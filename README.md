# 자유의 여신상 3D 착시 극장

기존 자유의 여신상 GLB 모델을 재활용하여 **카메라 없이** 스마트폰 화면에서 원근감 기반의 3D 착시를 체험하는 실험 프로젝트입니다.

## 실습 목적
- 기존 손가락 터치형 MR과 **카메라 없는 3D 착시 연출**을 비교합니다.
- 3D 모델이 멀리서 가까이 다가오는 연출과 손가락 회전·확대/축소를 체험합니다.
- 지원되는 스마트폰에서 기울이기 센서를 이용해 시점을 바꿉니다.

> 이 프로젝트는 실제 홀로그램이나 화면 밖으로의 광학 투영이 아닙니다. 일반 화면에 표현되는 원근 착시입니다.

## 준비 파일
- `index.html` — 웹페이지
- `statue_of_liberty_1.glb` — 기존 GLB 모델(권장: 새 저장소에도 복사)

GLB 파일을 새 저장소에 복사하지 않아도 기존 공개 저장소의 파일을 읽도록 예비 주소가 설정되어 있습니다. 다만 안정적인 실행을 위해 파일을 같은 저장소에 복사하는 편이 좋습니다.

## GitHub Pages 게시 방법
1. GitHub에 `statue-liberty-illusion-3d` 공개 저장소를 생성합니다.
2. `index.html`과 `statue_of_liberty_1.glb`를 저장소 최상위에 업로드합니다.
3. **Settings → Pages → Build and deployment**에서 `Deploy from a branch`, `main`, `/ (root)`를 선택하고 저장합니다.
4. 배포가 완료되면 `https://ilmac-knu.github.io/statue-liberty-illusion-3d/`에 접속합니다.

## 사용 방법
- **등장 다시 보기:** 멀리서 가까이 다가오는 연출 반복
- **자동 회전 정지/시작:** 모델의 자동 회전 제어
- **기울이기 사용:** 센서 지원 기기에서 시점 변화(권한 요청이 나타날 수 있음)
- **시점 초기화:** 손가락 회전과 확대 상태 초기화
- **한 손가락 드래그:** 회전
- **두 손가락 벌리기/오므리기:** 확대·축소
